# movie-explorer-app
This web application allows users to search and explore movies using a public API. It displays details like title, rating, year, and poster. Users can filter, sort, and mark favorites. The project demonstrates API integration, dynamic UI updates, and use of JavaScript functions like map, filter, and sort.

# Movie Explorer Web App

##  Overview
This is a web application that allows users to search and explore movies using a public API.

##  Features
- Search movies by name
- Filter movies by year/type
- Sort movies by rating
- Mark movies as favorites
- Responsive design

##  API Used
OMDb API (https://www.omdbapi.com/)

##  Technologies Used
- HTML
- CSS
- JavaScript (Fetch API)
